Semiconductor Yield Prediction & Root-Cause Analysis

Semiconductor Yield Prediction + Root-Cause Analysis · UCI SECOM Dataset

PythonXGBoostLightGBMOptunaSHAPscikit-learnimbalanced-learnONNX Runtime
↗ GitHub ↗ Live Dashboard ↗ Report

Five-stage ML pipeline for semiconductor yield prediction on the UCI SECOM dataset (1,567 samples × 590 sensors) — predicting wafer pass/fail before defects occur, then attributing failures to their root causes. Addressed extreme class imbalance (94:6) via SMOTE+RUS within a leak-safe imblearn Pipeline, tuned XGBoost with Optuna (100 trials), and cross-validated SHAP importance against Welch's t-test to surface 6 high-confidence failure signals with statistical backing. Final model achieves PR-AUC 0.227 and Recall 0.567 — mapping to an estimated $4.06M annual cost avoidance at production scale.

Leak-safe imblearn Pipeline — SMOTE+RUS resampling and StandardScaler scoped inside CV folds; prevents target leakage that inflates generalization metrics by up to 40% when applied before splitting.
XGBoost + Optuna tuning — 100-trial Bayesian optimization targeting PR-AUC on 590-feature sensor space; final model improves Recall 2.1× over baseline while controlling precision on a severely imbalanced dataset.
SHAP × Welch's t-test cross-validation — ranked features by SHAP mean absolute importance, then confirmed statistical separation (p < 0.05) via two-sample t-test; 6 sensors cleared both filters as high-confidence root-cause signals.
Business impact quantification — mapped Recall gain to defective wafer cost ($56K/unit) and estimated production volume; projected $4.06M annual cost avoidance to frame model deployment as a direct ROI decision.

KOSPI Anomaly Detection & Macro Factor Attribution

KOSPI Anomaly Detection + Macroeconomic Causal Analysis

Isolation ForestHMMSHAPOLS RegressionKRX APIFRED APITableauStreamlit
↗ GitHub ↗ Streamlit ↗ Tableau ↗ Report

Full-stack market intelligence system built on top of a KOSPI 100 anomaly detection pipeline. Extended Isolation Forest anomaly detection with Hidden Markov Model regime classification (bull/bear), OLS regression and SHAP-based macro factor attribution, and interactive Tableau Public + Streamlit dashboards — covering 1,500+ trading days from 2020 to 2026 across 5 macro indicators.

Market-wide anomaly detection across KOSPI 100 stocks using multivariate Isolation Forest on 6 engineered features — flags systemic stress when 10%+ of stocks are anomalous on the same day.
HMM Regime Detection on KOSPI index returns identifies bull/bear regimes; CUSUM change-point detection provides non-parametric cross-validation of regime transitions.
OLS + SHAP attribution identifies USD/KRW as the dominant macro driver of anomaly frequency (p<0.001); VIX and US 10Y yield also statistically significant.
Deployed on Streamlit Cloud + Tableau Public with 7 interactive tabs: Anomaly Detection, Feature Analysis, Cross-Stock Comparison, Market Event Validation, Macro Overview, Regime Analysis, Factor Attribution.
